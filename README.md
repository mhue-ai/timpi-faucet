# Timpi Faucet

A faucet for distributing Timpi/NTMPI tokens on the Neutaro chain.

## Status

🚧 **Under Development**

## Overview

This faucet enables controlled distribution of NTMPI tokens for:
- Testnet development and testing
- Community onboarding
- Agentic AI wallet bootstrapping

## Features (Planned)

- [ ] Rate limiting per address/IP
- [ ] Configurable drip amounts
- [ ] Anti-abuse measures (captcha, cooldowns)
- [ ] Admin dashboard
- [ ] Transaction logging and audit trail
- [ ] Integration with ClawPurse for wallet operations
